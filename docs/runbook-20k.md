# 第 2 轮操作手册:2 万 USDT

每一步:先运行命令,再对照「应该看到」。示例里的价格、数量、时间以实际为准,**格式和关键字一样就对**。
出现红字、`程序停止`、`HALTED`、`没对齐`,先停下,把输出发给 Claude。

全程:同一个网络(IP 要在 OKX API 白名单里);不要手动交易 OKX 的 ETH 永续;OSL 不要卖本轮以外的 ETH。

---

## 第 0 步(手动):转 2 万 USDT 进 OKX 交易账户

OKX App:资产 → 划转 → 资金账户 → 交易账户 → USDT → 20000。
交易账户里原来剩的约 52 USDT 不用管,程序只用这 2 万。

## 第 5 步(手动):把 ETH 转到 OSL

1. **OKX App 划转:** 资产 → 划转 → 交易账户 → 资金账户 → ETH → 数量填第 4 步「已买到」的数(例如 4.0735)。
   只划 ETH;USDT 和空单留在交易账户,继续对冲。
2. **OKX 提币到 hot wallet:** 网络选 **以太坊主网 / ERC20**(不要选 L2),地址和第 1 轮一样,核对前后几位。数量填全部。
3. **hot wallet → OSL ETH 充值地址:** 用钱包的「Max」,让钱包自动留 gas。
4. **OSL 到账后:** 从 OSL 资金账户划到交易账户。
5. **记下 OSL 充值记录里本次入账的 ETH 数量**(例如 4.0731)。

大额可能被审核、晚到账;期间空单一直对冲,不用急,只会多几笔很小的资金费。

## 第 6 步:OSL 卖出 + 程序自动平空

打开卖出助手(窗口全程开着,直到卖完):

```bash
uv run offramp sell --maker
```

先填到账数量(第 5 步记的入账数):

```
本轮买到(扣手续费后)4.0735 ETH;OKX 空单 4.073 ETH
OSL 交易账户实际到账多少 ETH?(...)> 4.0731
[..] 已记录到账 4.0731 ETH。转账损耗 0.0004 ETH,多出来的空单现在平掉
[..] 对齐 空单 4.073 ETH ≈ 剩余 4.0731 ETH ✓

 OSL ETHUSD   买一 24xx   卖一 24xx
 OKX 永续       卖一 24xx
 剩余待卖 4.0731 ETH ≈ 99xx USD   已卖 0 / 到账 4.0731
 ▶ OSL 挂限价单后等待实际成交,输入 sold <本轮累计成交 ETH>;OKX 用 IOC 买入平空
>
```

如果入账数比「本轮买到」还多(hot wallet 里原来有别的 ETH),程序会问是否只按买到的处理,输入 `y`。

### OSL 挂单规则(每张)

| 栏位 | 填 |
|---|---|
| 类型 | 限价 |
| 卖出价 | **卖一 − 0.01**,且**必须高于买一**;卖一和买一只差 0.01 时就填卖一 |
| 卖出量 | 第 1~3 张各 **1 ETH**;第 4 张填**全部剩余** |
| 执行方式 | 有「只做 Maker」就选;没有用 GTC |

价格跑开一直不成交:OSL 撤单,按新的「卖一 − 0.01」重挂。

### 每次成交后,在 `>` 后输入**累计**卖出数,再输入 `y`

```
> sold 1
累计 1 ETH,即本次新增 1 ETH,将在 OKX 平掉 1 ETH 空单。确认输入 y,其他取消> y
[..] 累计卖出 1 ETH,本次新增 1 ETH
[..] OKX 买入平空 1 ETH @ 2445.21
[..] 对齐 空单 3.073 ETH ≈ 剩余 3.0731 ETH ✓

> sold 2
累计 2 ETH,即本次新增 1 ETH,将在 OKX 平掉 1 ETH 空单。确认输入 y,其他取消> y
[..] OKX 买入平空 1 ETH @ 2444.81
[..] 对齐 空单 2.073 ETH ≈ 剩余 2.0731 ETH ✓

> sold 3
累计 3 ETH,即本次新增 1 ETH,将在 OKX 平掉 1 ETH 空单。确认输入 y,其他取消> y
[..] OKX 买入平空 1 ETH @ 2444.58
[..] 对齐 空单 1.073 ETH ≈ 剩余 1.0731 ETH ✓

> sold 4.0731
累计 4.0731 ETH,即本次新增 1.0731 ETH,将在 OKX 平掉 1.0731 ETH 空单。确认输入 y,其他取消> y
[..] OKX 买入平空 1.073 ETH @ 2444.46
[..] 对齐 空单 0 ETH ≈ 剩余 0 ETH ✓
[..] 本轮卖完。下一步:offramp round close,然后 offramp report --osl-usd <OSL 实际收到的 USD>
```

**规则:**
- `sold` 后面永远填**本轮累计**卖出总数,不是这一次的数。
- 确认提示里的「本次新增」要和你刚成交的数量对得上;对不上就输入 `n` 取消,重新输。
- 只成交一部分:报已成交的累计数(例如 `sold 1.4`);只挂出没成交:什么都不输。
- 同一个数输两次不会重复平仓。
- 中途离开:输入 `q`(空单保留);回来再运行 `uv run offramp sell --maker` 继续,不会再问到账数量。
- 平空失败的红字:先别在 OSL 继续卖,输入 `m` 重试。实在连不上 OKX,到 OKX 网页手动平掉对应数量的 ETH 永续空单。

## 第 8 步:对账

把 OSL 本轮所有卖单的「成交金额 − 手续费」加起来,填进去:

```bash
uv run offramp report --osl-usd <OSL 本轮实际收到的 USD>
```

应该看到:

```
====== 第 2 轮对账(closed)======
本轮开始时交易账户 USDT          20052.05
本轮结束时交易账户 USDT          100xx.xx
→ 消耗 USDT                       99xx.xx
OSL 收到 USD(你输入)            99xx.xx
→ 实际兑换率                      0.99xxx USD/USDT
...
OKX 核对:按订单算应消耗 ...,实际 ...,未解释差额 0.0000 ✓
```

预计兑换率约 0.996~0.997。结束后 OKX 交易账户会剩约 1 万 USDT(保证金退回),可以留着跑下一轮。
